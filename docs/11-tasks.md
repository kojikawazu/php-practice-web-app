## 進捗メモ

> テスト規模（ケース数・正常/異常の比率）の正本はここに置く。各 PR 完了時点の実測値であり、テストを増減させた PR で更新する。`docs/08`（戦略・ケース一覧）と `docs/12`（読む順番）では件数を持たない。
