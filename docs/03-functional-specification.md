## ユーザーフロー

- 未ログインで保護ページ（`/tasks` 等）へアクセス → ログイン画面へ誘導
- `/register` でユーザー登録 → 自動ログイン → タスク一覧
- `/login` でログイン → タスク一覧（自分のタスクのみ表示）
- タスクの追加・編集（タイトル変更）・完了切替・削除（自分のタスクのみ）
- 一覧はタイトル検索（`q`）とページネーション（5 件/ページ、`page`）に対応
- ログアウト → ログイン画面
- api はトークン認証: `register`/`login` で取得した token を Bearer 送信
