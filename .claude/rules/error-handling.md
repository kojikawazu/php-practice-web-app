# エラーハンドリング

- **バリデーション必須**: ユーザー入力・外部入力は必ず検証する。Laravel は `$request->validate()`、Laminas は InputFilter で行う（`docs/03` / `docs/07`）。
- **HTTP ステータスコード**: 適切なステータスで返す。作成 201 / 削除・ログアウト 204 / 未認証 401 / 認可外・不在 404 / バリデーション 422 / サーバエラー 500。
- **所有者スコープの隠蔽**: 他人のリソースは存在を伏せて 404（Laravel）/ 対象外として無視（Laminas）とする（`docs/06`）。
- **統一エラーレスポンス（API）**: laravel-api は Laravel 標準の `{ "message": ..., "errors": {...} }` 形式（422）に統一する。
- **ログ**: エラー時はスタックトレースを含めてログ出力する。パスワード・トークン等のセンシティブ情報はログに含めない。
- **外部通信の失敗**: URL プレビュー等の外部取得はタイムアウト・サイズ上限・例外（`BlockedUrlException` 等）で安全に失敗させ、ユーザー操作は継続可能にする（`docs/06`）。
